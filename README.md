# 人话翻译器

**听懂弦外之音，说出言外之意。**

把聊天和日常沟通中的「话里有话」，翻译成更容易理解、更得体、更好回复的人话。

## 功能一览

- **潜台词翻译**：输入别人说的话，看懂字面意思、可能的潜台词、语气线索和其他解释。
- **语气转换**：输入自己想说的话，在高情商、职场专业、温柔委婉、礼貌坚定等 9 种语气之间转换。
- **帮我回复**：粘贴收到的消息，按温和自然、高情商得体、幽默轻松、简洁有边界等策略生成可直接发送的回复。
- **情绪与语气分析**：识别主要语气线索，给出文字依据和把握程度，不武断下结论。
- **历史记录**：成功的分析自动保存到本机，可查看详情、单条删除、二次确认清空。
- **收藏**：结果中的任意一条内容可单独收藏，与历史分开管理。
- **今日沟通签**：每天一句轻量沟通提醒，可随机换一句。
- **设置**：自动保存开关、一键清除本机数据、隐私说明。

所有历史和收藏只保存在当前设备的浏览器存储中，不上传服务器。

## 技术栈

- Expo (React Native) + Expo Router，默认平台为 Web
- TypeScript
- Supabase Edge Function 作为 AI 服务代理（API Key 只存在服务端，不会进入网页代码）
- 本地存储使用浏览器 localStorage

## 本地开发

环境要求：Node.js 18+，npm。

```bash
npm install
npm run dev
```

启动后按提示打开网页预览。其他常用命令：

```bash
npm run typecheck   # 类型检查
npm run build:web   # 构建网页版本
```

## 配置 AI 服务

翻译功能通过服务端代理调用兼容 OpenAI 风格接口的大模型。需要在 Supabase 边缘函数中配置三个密钥：

| 密钥 | 说明 |
|---|---|
| `AI_API_KEY` | AI 服务商的 API Key |
| `AI_BASE_URL` | 接口地址（可选，默认 `https://api.openai.com/v1`） |
| `AI_MODEL` | 模型名称，例如 `gpt-4o-mini` |

配置好之后，无需重启或重新部署，翻译功能即可使用。

### 未配置 AI Key 时的表现

应用本身可以正常浏览和使用：模式切换、场景选择、示例填入、历史、收藏、今日沟通签都不依赖 AI。只有点击「翻译 / 润色 / 生成回复」时会显示「AI 服务尚未配置」的友好提示，不会伪造分析结果。

## 使用说明

- 主文本最多 3000 字，补充上下文最多 1500 字，超出后无法提交。
- 输入内容会发送给所配置的 AI 服务商进行分析，请避免粘贴密码、证件号、银行卡号等敏感信息。
- 「潜台词」类结果是参考解读，不代表对方真实想法；重要决定请不要只依赖单条消息的分析。

## 常见问题

- **点击翻译提示「AI 服务尚未配置」**：按上一节说明配置 `AI_API_KEY` 和 `AI_MODEL`。
- **提示请求超时**：网络波动或模型响应慢，稍后重试即可。
- **历史记录不见了**：历史保存在当前设备的浏览器里；换设备、换浏览器或清除了浏览器数据都会导致记录不可见。
- **想彻底删除本机数据**：进入「设置」标签，点击「清除本机数据」并二次确认。
